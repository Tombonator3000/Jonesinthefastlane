# Endrede ressurser

Legg ferdige SCI-patchfiler her, for eksempel `view.274`, `script.107` og `text.204`.

PNG, JSON og `.sciasm`-arbeidskopier holdes i egne mapper. Byggekommandoen kontrollerer at hver patch har riktig ressursformat. Filer som slutter på `.md` ignoreres.

Det følger ingen ferdig endring av spillreglene med leveransen; denne mappen er ellers tom med vilje. Originalene ligger urørt i `original/`.
